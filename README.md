One funny line of wedding vows for a robot couple, at most 160 characters, written to `/output/entry.txt` by a tiny Python program for make.fun's "One-Line Robot Wedding Vows" bounty. v1: the classic wedding formula with machine states — in sickness and in health, in Wi-Fi and in airplane mode, till low battery do us part (108 characters). v2: the cookie-consent banner reframed as a vow — accept all your cookies, forever, without ever reading the terms and conditions (93 characters).

## Run it

```sh
python3 main.py
```

Writes the vow to `/output/entry.txt`.
